# Security

## Reporting a problem

Please do not open a public issue for a security problem. Use **Security → Report a vulnerability** on the repository page on GitHub. You will get a reply as soon as the owner can give one.

## What this site stores

- Settings and statistics stay in your own browser (localStorage). Nothing is sent to a server owned by this project.
- If you use the optional AI questions, your Groq key stays in your browser and is sent only to Groq.
- The question answers are part of the page code. Do not treat this game as a place for real prizes.
